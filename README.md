# 扩圈

### AI 时代的长秩序原理

> 一个秩序能活多久，取决于它把多少人算作「我们」。

---

## 这是什么书

**《扩圈》**讨论一个古老而紧迫的问题：**什么样的秩序，能活得比缔造它的人更久？**

它的答案不是「更聪明」「更强」「技术更先进」，而是更朴素的一点：

> **秩序的边界，就是「圈」的边界；圈的半径，决定秩序的寿命。**

- 窄圈靠恐惧与榨取维持：爆发力强，衰亡极快。
- 宽圈靠信用与互惠维持：启动慢，极其耐用。

这不是道德判决，是**统计结果**。榨取型秩序系统性早亡，涵容型秩序系统性长寿——而绝大多数统治者在**关键时刻**都会选错，因为窄圈在短期内永远更划算。

站在 AI 时代的路口，这个问题第一次变得生死攸关：**当机器可以替代绝大多数人的经济功能，统治者是否还需要「人民」？** 本书的回答是——**需要，而且比以往任何时候都更需要**。因为合法性是唯一买不到的东西。

## 怎么读

- **如果你手中有权**：把它当一份检查表。每一条制度、每一个决策，问一句——**它把多少人算作「我们」？**
- **如果你无权**：把它当诊断工具。看清自己处在哪个圈层、被谁划在了外面、以及这套秩序还能撑多久。
- **如果你只想读一章**：读第 11 章「AI 时代」。

## 构建电子书

需要 [pandoc](https://pandoc.org/)（生成 PDF 还需要 xelatex 与一款中文字体）。

```bash
./build/build.sh          # 生成 build/扩圈.epub 与 build/扩圈.html
./build/build.sh pdf      # 额外尝试生成 PDF（需 xelatex + 中文字体）
```

> 如果你的 pandoc 是精简版、缺少数据模板，可指定数据目录：
> `PANDOC_DATA_DIR=/path/to/pandoc/data ./build/build.sh`
