# Translation Glossary & Style Guide

This file governs the English edition of 《扩圈》 (*Expanding the Circle*).
Every translator MUST follow it so the terminology stays consistent across chapters.

## The one rule above all
Keep the voice of the original: **cold, terse, unsentimental, aphoristic.**
Short sentences. No filler. No academic hedging. No emoji. Preserve the original's
`>` pull-quotes and bolded theses exactly in position. Do not add or remove content.
When the Chinese is blunt, the English must be blunt too.

## Section headers (translate consistently)
- `# 序言 · X` → `# Preface · X`
- `# 第 N 章 · X` → `# Chapter N · X`
- `# 结语 · X` → `# Epilogue · X`
- `# 后记 · X` → `# Afterword · X`
- `## 一、核心命题` → `## 1. The Core Claim`
- `## 二、证据` → `## 2. The Evidence`
- `## 三、机制` → `## 3. The Mechanism`
- `## 四、代价与反例` → `## 4. Costs and Counterexamples`
- `## 五、AI 时代的回响` → `## 5. Echoes in the Age of AI`
- `## 六、本章小结` → `## 6. Chapter Summary`
- `（本章即回响）` → `(this chapter is itself that echo)`
- `### 机制一/二/三/四：X` → `### Mechanism 1/2/3/4: X`

## Hard rules
- Preserve markdown exactly: same headings in the same order, same `>` quotes, same bold.
- Do NOT invent facts, numbers, or quotes not in the Chinese source.
- If a Chinese idiom has no clean English equivalent, translate its meaning, not its words.
- Output to `en/NN-slug.md` with the SAME filename as the Chinese source.
- No YAML front matter. No "（本章完）" / "(end of chapter)".
